# ida-window-title-randomizer

- tested on ida pro 9.4
- might work on lower versions idk

# q: what is this
read the title.

# q: how does it work
runs a continuous loop that looks for the ida window class, if found the plugin will attempt to randomize the windows title to a 32 character string

# q: what does this prevent
shitty anticheats using from window title detection against your precious ida pro instance

# q: how do i use this for myself
place the .py script into C:\Program Files\IDA Professional 9.4\plugins
